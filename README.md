### Hi, I'm Abdulazeez.

I build web apps, mostly React, mostly for people who wouldn't otherwise get software built for them. Based in Ilorin, Nigeria.

Right now I'm writing React at Manaknight, and building a QA issue tracker on the side after watching a company I worked at run bug tracking through shared spreadsheets — that one's called Veridex, still cooking.

A few things I've shipped:
- **Manhaj** — an offline audio library for Nigerian scholars
- **Aqua** — a little macOS-style desktop for WSL, backed by a Rust daemon
- **RentLedger** — rent tracking for landlords and tenants who split payments
- **Sahnaf** — a commerce + solar platform with its own pricing calculator

More on all of it: **[myportfolio-sage-pi.vercel.app](https://myportfolio-sage-pi.vercel.app/)**

Mostly living in React, Next.js, TypeScript, Node, and Postgres these days. Poking at Rust on the side.
